# Autonomous AI Agent Systems and Orchestration

Coursework, assignments and notes for the **Autonomous AI Agent Systems and Orchestration** Specialization by **Edureka** on Coursera.

> Specialization: <https://www.coursera.org/specializations/autonomous-ai-agent-systems-and-orchestration>
> Course list: <https://www.coursera.org/specializations/autonomous-ai-agent-systems-and-orchestration#courses>

## About the specialization

The program teaches how to design, build and manage intelligent AI agents that can reason, act and collaborate autonomously: from single-agent architecture to multi-agent systems and production-grade orchestration and scaling.

| | |
|---|---|
| **Provider** | Edureka |
| **Level** | Intermediate |
| **Duration** | ~8 weeks at 5 h/week (23 h of course content) |
| **Format** | 100% online, 3-course series |
| **Certificate** | Shareable Coursera certificate |

**Skills:** Agentic systems, generative AI agents, tool calling, memory management, prompt engineering, RAG, LLM applications, workflow management, systems integration, responsible AI.

**Tools:** LangChain, LangGraph, AutoGen, CrewAI, OpenAI, Google Gemini.

## Repository workflow

- `main` holds the overview, the folder structure and the **finished** work of each course.
- Each course is developed on its **own branch** (`course-0N-...`).
- When a course is completed, its branch is merged into `main`.
